# MONO CI B0/Ψ execution requirement-to-test matrix

| Requirement | Implementation behavior | Test |
|---|---|---|
| EXEC-01 deterministic case materialization | Materializes only source files from pinned commit/bundle objects; verifies exact Git repository/application trees and produces repeatable, separate B0/Ψ bundles. | `test_common_inputs_are_repeatable_equal_and_separate_by_arm` |
| EXEC-02 baseline provenance | Rejects digest drift and any attempt to call the reconstruction historical or approved. | `test_reconstruction_is_explicitly_prospective_and_source_pinned`; `test_arm_bundle_readback_detects_tampering_and_symlinks` |
| EXEC-03 no-go preservation | Official entrypoint refuses execution under the existing NO_GO/P-not-ready guards; frozen preflight still reports NO_GO. | `test_official_execution_stops_at_existing_readiness_and_method_guards`; `test_preflight_is_repeatable_no_go_and_never_reports_measurements` |
| EXEC-04 B0 behavior | DEVELOPMENT runner executes the two bound evaluator calls, records raw output identities and duration, and emits no operation or governance decision. | `test_development_runner_records_b0_probe_and_keeps_psi_blocked` |
| EXEC-05 Ψ behavior | Ψ remains blocked by the existing readiness guard, with no prediction, operation or governance output. | `test_development_runner_records_b0_probe_and_keeps_psi_blocked`; `test_official_execution_stops_at_existing_readiness_and_method_guards` |
| EXEC-06 arm parity and isolation | Creates separate bundle/output roots; verifies equal common inputs and rejects scorer/scoring, expected-output, `.git`, symlink, and unsafe paths. | `test_common_inputs_are_repeatable_equal_and_separate_by_arm`; `test_method_input_rejects_scorer_expected_and_git_paths`; `test_arm_bundle_readback_detects_tampering_and_symlinks` |
| EXEC-07 source evidence freshness | Every actual B0 evaluator record binds to its case commit/tree and pinned evaluator/config digests; stale bindings are rejected. | `test_evaluator_records_reject_stale_or_wrong_evaluator_bindings`; `test_development_runner_records_b0_probe_and_keeps_psi_blocked` |
| EXEC-08 status preservation | Applicability/validity remain UNKNOWN or NOT_EVALUABLE; missing values cannot become numeric zeros or PASS. | `test_metric_statuses_remain_categorical_and_no_scoring_is_emitted`; `test_unknown_applicability_incomplete_denominator_and_missing_reference_stay_explicit` |
| EXEC-09 output integrity and timer boundary | Raw evaluator outputs, the run record and complete directory inventory are checksummed; the case timer wraps evaluator work and raw-output checksum sealing. | `test_development_result_readback_rejects_changed_output`; `test_development_runner_records_b0_probe_and_keeps_psi_blocked` |
| EXEC-10 scorer separation | The arm-input verifier rejects scorer material; a separate post-run scorer gate reads a sealed record and emits only categorical statuses until an independently approved reference exists. | `test_method_input_rejects_scorer_expected_and_git_paths`; `test_development_result_readback_rejects_changed_output` |
